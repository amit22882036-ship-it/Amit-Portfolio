# Amit Gertner | Engineering Portfolio

A personal portfolio presenting my engineering projects, technical skills, education, and professional background as a Data Science and Engineering student at the Technion. It provides a concise overview of my work in full-stack development, AI engineering, and data analysis, with project details and links to public source code.

**[Visit the portfolio](https://amit22882036-ship-it.github.io/Amit-Portfolio/)** · **[Portfolio source](https://github.com/amit22882036-ship-it/Amit-Portfolio)**

## Website technologies

The portfolio is a static website built with HTML, CSS, and JavaScript ES modules. It uses Bootstrap 3 for layout, jQuery and Waypoints for interactions, CSS animations, and Font Awesome icons. GitHub Pages hosts the published site. No package installation or build step is required.

The site includes responsive project cards, a shared project details modal with an image gallery, and light and dark themes.
